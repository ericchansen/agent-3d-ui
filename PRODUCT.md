# Agent 3D

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

An open-source synthetic 3D object editor/viewer demonstrating an agent interacting with an application. Reuse native tooling; keep scene state and edit approval authoritative on the backend.

The example supports inspecting and highlighting objects, plus approved color and absolute-position changes. It does not support CAD import, object creation/deletion, collaboration, or undo.
