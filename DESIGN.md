# UI constraints

- The scene is the workspace; chat supports it.
- Use plain Arial text, regular labels, and restrained headings.
- Keep object IDs and shape details in the selected-object inspector.
- Reuse CopilotKit messages, input, suggestions, and tool activity.
- Do not add welcome headlines, decorative branding, or diagnostic panels.
- Keep application control styles out of native chat components.
- Text must fit at the actual panel width, including an empty placeholder.
- Preserve keyboard selection, touch controls, and the non-WebGL inspector.
- Preview exact pending arguments; only server state confirms a committed edit.
- Do not add a second approval, conversation, or state-management system.
